# 🎬 CineMatch

**CineMatch** es una plataforma inteligente de recomendación de películas basada en análisis de datos profundos a partir de perfiles de FilmAffinity.

## 🚀 Features

- 🚫 **Películas Malditas**: Películas que contradicen tus sesgos pero te encantarán.
- 📅 **Timeline Cinemático**: Evolución de tus gustos y eras cinematográficas.
- ⚡ **Algoritmo de la Sorpresa**: Predicciones de discrepancia entre tu voto esperado y real.
- 🤔 **Cine Contrafáctico**: Simulación de escenarios de preferencias alternativos.
- 💔 **Películas Gemelas Ocultas**: Recomendaciones por clusters de respuesta emocional.
- 🔍 **Traductor de Crítico**: Análisis de tu sesgo por director, presupuesto, tono o género.
- 🔮 **Descubridor de Tendencias**: Gemas ocultas con alto potencial y baja visibilidad.
- ⛔ **La Película Prohibida**: Títulos que rompen tus barreras habituales.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express, Puppeteer/Cloudscraper, Redis Cache, TMDb API.
- **Frontend**: React 18, Vite, Tailwind CSS, Recharts, Lucide Icons.
- **CI/CD & Hosting**: GitHub Actions, GitHub Pages, Vercel.
